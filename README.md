# वर्षा समाधान AI

श्रीमती वर्षा जी की स्मृति में — एक पूरी तरह **निःशुल्क** समाधान सेवा।

बच्चों से बुज़ुर्गों तक, हर किसी के लिए। बोलकर या लिखकर पूछिए, सरल हिंदी में उत्तर पाइए।

## चलाने का तरीक़ा

पहली बार:

```
npm install
npm run setup     # database + जानकारी + review नमूने + 4K चित्र
```

उसके बाद सिर्फ़ `npm run dev`।

खोलिए: **http://localhost:3001**

## AI कैसे जोड़ें

बिना key के भी सब काम करता है — यूज़र को पहले से लिखी जानकारी दिखती है।

1. https://aistudio.google.com/apikey पर मुफ़्त key बनाइए (2 मिनट)
2. `.env` में डालिए:
   ```
   GEMINI_API_KEY="आपकी key यहाँ"
   ```
3. Server restart कीजिए

**मुफ़्त plan में सीमा है** (प्रतिदिन की संख्या तय है)। इसलिए `.env` में यह भी है:

```
GEMINI_DAILY_REQUEST_LIMIT="40"
```

सीमा पूरी होने पर site रुकती नहीं — यूज़र को पहले से लिखी जानकारी दिख जाती है, और एक संदेश मिलता है कि कल फिर पूछ सकेंगे।

## सूरज और चित्र

सूरज **SVG** से बना है — emoji नहीं। Emoji हर फ़ोन पर अलग दिखता है, और पुराने Android पर खाली बक्सा बन जाता है।

**3D चित्र ray-traced हैं** — असली light, असली बादल, असली धुंध। किसी और की तस्वीर नहीं, इसलिए copyright का कोई सवाल नहीं।

```
npm run art            # 4K में बनाएँ (3840×2160 आदि)
npm run art:preview    # छोटा नमूना, जल्दी देखने के लिए
```

## मूल prototype की 16 ग़लतियाँ, और उनका हल

आपके बनाए एक-फ़ाइल वाले prototype में जो ग़लतियाँ थीं — सब ठीक की गई हैं:

| # | ग़लती | असर | अब |
|---|---|---|---|
| 1 | `askAI()` खाली था | वेबसाइट की मुख्य सुविधा काम ही नहीं करती | असली AI, key server पर |
| 2 | API key browser में | कोई भी `Ctrl+U` दबाकर चुरा लेता | key सिर्फ़ server पर |
| 3 | `results[0][0]` | दो बार बोलने पर पहले वाला जवाब | `results[length-1]` — नया जवाब |
| 4 | 9 श्रेणियाँ `div` थीं | **एक भी keyboard से नहीं खुलती** — बुज़ुर्ग/नेत्रहीन बर्फ़र | सब असली `<button>`/`<a>` |
| 5 | 320px पर 82px ओवरफ़्लो | ध्वनि बटन कटे हुए | सब स्क्रीन ठीक, जाँची गई |
| 6 | माइक बटन का नाम नहीं | screen reader को पता ही नहीं चलता | `aria-label` |
| 7 | 0 हिंदी आवाज़ मिलीं | सुनाने पर चुपचाप कुछ नहीं | ग़लती का साफ़ संदेश |
| 8 | `<form>` नहीं | **Enter दबाने से कुछ नहीं** | असली form |
| 9 | `<main>`/`<header>` नहीं | screen reader导航 नहीं कर सकता | सब landmarks |
| 10 | WhatsApp meta नहीं | लिंक भेजने पर खाली पता दिखता | पूरा OG tag |
| 11 | `playDhun()` = `alert()` | **झूठ** — "धुन बज रही है" कहकर कुछ नहीं | असली Web Audio ध्वनि |
| 12 | `outline: none` | keyboard user के लिए पन्ना बेकार | हमेशा focus ring |
| 13 | `h1` के बाद सीधे `h3` | SEO और accessibility खराब | सही क्रम |
| 14 | बहुत तेज़ आवाज़ | बुज़ुर्ग सुन ही न पाए | गति 0.85 |
| 15 | कोई database नहीं | कुछ बदलने का कोई तरीक़ा नहीं | SQLite + admin |
